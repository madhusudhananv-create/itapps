Add Process Model

Process-model can be created/edited/deleted under the tab Add process model.






Add Process Area

Process Area can be created/edited/deleted using the button Add New Process Area on the left.









Map Process to Process Area

Click Map Process to Process Area button on left side to Map Process to Process Area.






Map Process Model to Process

Choose Process model and Process area. The processes related to that process area will be checked. On clicking save button the mapping will be saved.






View already mapped process model and processes

Processes mapped to process model can be viewed by using the filter ‘Filter By Process Model’ and ‘Filter by Process area’ on right side.






Add Service Tower

Service Tower can be created/edited/deleted using the button Add Service Tower on left side.









Map Service Tower to Process

Choose Service Tower and Process area. The processes related to that process area will be checked. On clicking the save button mapping will be saved.






View already mapped Service Tower and Processes

Go to tab View Service Tower & Process. We can view Service Tower & Process by using the filter ‘Filter By Service Tower’ and ‘Filter by Process area’ on the right side.






Map Service Tower/Process model/Process to a specific project

Go to tab PSPD. Select any Customer and Project. Add applicable Service Tower from the dropdown given below.




Select any Service Tower to map applicable Processes.Then click on save changes.






Add a Checklist

Go to tab Setup Checklist. Enter Title, Description and fill all the necessary details for the Checklist. Then click on the save button.






Revise a Checklist

Click on the Revise button for the Checklist you want to revise. All the question in the original Checklist will be copied to the newly revised Checklist. The new checklist will have a revised version number and effective date starting today.






Choose an applicable Status list

Under the Setup Checklist click on the plus(+) button near the field Choose an applicable Status list. Enter the Status title and corresponding Pass,Fail,Not applicable and mutiplier value.









Add questions to a checklist

Go to tab Map Checklist questions and Process. Select checklist, Service Tower, Process Area, Process and click on the plus(+) button to add a question.

Note: Display order denotes the order in which the questions should come in the checklist.


If a checklist is used in an audit, it can not be added. We need to revise a checklist and start adding the questions.




Schedule an assesment

Go to Manage Event/Task under the tab View Planner. Fill the appropriate details to schedule an assesment.






View scheduled event

Go to Planner under the tab View Planner. Fill the appropriate details to view the events.
